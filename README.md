# 🌙 O Clone: A Data Story

Interactive storytelling dashboard based on the Brazilian telenovela **"O Clone" (2001-2002)**.

🔗 Live Demo:  
https://clone-dashboard-jmi4fzhxm4qdz4h4kuqgxh.streamlit.app/

---

## About the Project

This project transforms a nostalgic TV series into an interactive data storytelling experience.

All metrics were collected manually from episode summaries and transformed into animated visual narratives using Python and Streamlit.

Instead of building a traditional business dashboard, the goal was to explore:
- narrative patterns
- emotional dynamics
- recurring character behaviors
- visual storytelling through data

---

## Features

### 📈 Jade vs Leo Escape Timeline

Animated cumulative comparison between:
- Jade escaping to Lucas
- Leo (the clone) repeating the same behavioral pattern 20 years later

### 🔨 Ali's Patriarchy Meter

Interactive carnival-style strength tester visualizing Ali's control level throughout the series.

### ☕ Zoraide Predictions

Interactive coffee-ground fortune telling section with animated flip cards.

All five predictions made during the series eventually come true.

### 🎨 Custom Visual Design

The dashboard combines:
- Plotly
- Streamlit
- custom HTML/CSS/JS components
- AI-generated visuals
- narrative UI design

## Dataset

- 221 episodes analyzed
- 247 rows of manually structured data
- Built from publicly available episode summaries

Metrics include:
- escape attempts
- relationship dynamics
- engagements and weddings
- Ali's control score
- Zoraide predictions

## Why This Project?

Most beginner data projects focus on:
- sales
- finance
- marketing KPIs

This project explores a different direction:
**data storytelling through pop culture narrative analysis**.

The goal was to create something memorable, emotional, and visually distinctive.
